# さわれる実験室（touch-lab）

**予想して、さわって、たしかめる。** 物理の法則を自分の手で試せる学習シミュレーション。

- **自由実験室**（`/sandbox`）: まっさらな世界に物体を置いて動かす物理サンドボックス（v0.2 で追加）
- **もしも計算機**（`/whatif`）: 「全人類が東へ走ったら？」のような地球規模の実験を、実際の式と測定値で計算（v0.2 で追加）
- **物理クエスト**（`/physics`）: 予測→さわる→採点→解説の学習クエスト 3 本（v0）

**公開URL: https://touch-lab-one.vercel.app**

予測する → パラメータをさわる → 実行 → 予測とのズレを採点 → 解説で納得、のループを全クエスト共通の「殻」にしています。

## v0 の中身（物理・力学モジュール）

| クエスト | さわれるパラメータ | 計算方法 |
|---|---|---|
| Q1 斜面スライド | 摩擦係数 μ | 式 `a = g(sinθ − μcosθ)`、`t = √(2L/a)` |
| Q2 自由落下レース | 質量（2球）・空気抵抗 ON/OFF | RK4 数値積分（0.001 秒刻み）、空気抵抗は `F = ½ρC_dAv²` |
| Q3 重力切替チャレンジ | 重力加速度（プリセット＋カスタム） | RK4 数値積分（0.001 秒刻み） |

- 物理エンジン（Matter.js 等）は使っていません。式と自前の数値計算です（`src/lib/physics.ts`）。
- 解説カードには必ず前提条件（空気抵抗なし、静止摩擦＝動摩擦とみなす 等）を書いています。
- 進捗とスコアはブラウザの localStorage にだけ保存します。ログイン・DB・外部送信はありません。
- 結果は共有テキスト（コピー／LINEで送る）で友だちに送れます。

## 自由実験室（/sandbox）

自作の 2D 物理エンジン（`src/lib/engine/engine.ts`）で動く、何でも試せる実験場です。

- **道具**: つかむ／円／箱／坂／板／ピン（回る軸）／モーター／棒／ひも／ばね／ふきとばす／消す
- **物体**: 材質（木・鉄・ゴム・氷・石・発泡スチロール）、質量、初速、はねかえり、摩擦を変えられる
- **世界**: 重力（無重力〜太陽の表面、マイナスで上向き）、空気抵抗と空気の濃さ（火星〜金星）、物体どうしが引き合う万有引力（G の大きさも変更可）、再生速度
- **表示**: 軌跡、速度の矢印、ものさし、2本指で拡大縮小
- **保存**: タイトル（何でも自由）とメモをつけて端末に保存。共有リンクは実験の中身を圧縮して URL の `#` の後ろに入れるので、サーバーには何も送らない
- **サンプル**: ピタゴラ風ドミノ／ふりこ・ばね・二重ふりこ／惑星の軌道／モーターの車／月で積み木くずし／空気が10倍こかったら

エンジンの中身: 円と凸多角形の衝突（分離軸判定＋辺のクリッピングで最大2点の接触）、逐次インパルス法（10回反復・前の刻みの力を引き継ぐウォームスタート）、クーロン摩擦、はねかえり、ピン・棒・ひも（たるむ）・ばね（陰的に解いて硬くても安定）・モーター。1 刻み 1/240 秒。物体は「奥行き 1m の板」として質量と空気抵抗を計算します。

## もしも計算機（/whatif）

| もしも | 使う式 |
|---|---|
| 全人類が同時に東へ走ったら | 角運動量保存 `ΔT = T·N·m·v·R·cosφ / (I·ω)` |
| 全人類が同時にジャンプしたら | 重心は動かない `d = N·m·h / M地球` |
| 地球の自転が急に止まったら | `v = ω·R·cosφ` |
| 地球の反対側まで穴をほって飛びこんだら | 単振動 `t = π√(R/g)` |
| 月が今よりずっと近かったら | 潮の力 `∝ 1/d³`、ケプラーの第3法則 |
| 重力が○倍になったら | `h = v²/2g`、`T = 2π√(L/g)`、フルード数 |

各ページに「前提条件」と、実在のものとくらべる対数の「ものさし」があります。自分で考えた「もしも」は、タイトルをつけて自由実験室で作れます。

## 開発

```bash
npm install
npm run dev      # http://localhost:3000
npm run verify   # 物理計算の検証（理論値との誤差）
npm run build
```

技術: Next.js 16（App Router）＋ TypeScript ＋ Tailwind CSS v4。描画は Canvas 2D。
